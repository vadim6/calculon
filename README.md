# Calculón

Android app for practicing multiplication and division in the **Spanish visual method** — the layout taught in Spanish primary schools (Primaria), which differs from US/UK formats.

Built for a 9-year-old.

## Features

- **Multiplication** — levels 1–3 (single×single → 3-digit×2-digit), with adaptive difficulty based on streak
- **Division** — dividend up to 999, divisors 2–9, with remainder
- Both operations rendered in the authentic Spanish layout using Jetpack Compose `Canvas`
- Step-by-step guided solving — one digit at a time
- Custom number pad (no system keyboard)
- Spanish UI throughout

## Tech

Kotlin · Jetpack Compose · MVVM · No backend · Min SDK 26
